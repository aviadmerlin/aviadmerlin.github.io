TennisVoiceScore

A hands-free iOS tennis score tracker controlled entirely by voice, in Hebrew and English, no tapping during the match.

Solo project · working prototype, not published to the App Store
Swift SwiftUI Speech framework

Problem

Keeping score mid-match usually means stopping to tap a phone, or arguing about what the score actually was. I couldn't find an app that handled this fully hands-free, so I built one.

What I built

  • Voice commands in Hebrew and English: point to a player, read the current score, undo the last point
  • Full tennis scoring logic: points to games, deuce, advantage, handled according to the official rules
  • Spoken score announcements after every point, using Azure text-to-speech through a Cloudflare Worker, with a system-voice fallback
  • Bilingual UI, Hebrew and English
  • Bluetooth earbud support, so both players hear the score without looking at a phone

Result / status

This is a solo, working prototype, built and tested on a real device (voice recognition needs a microphone, so it doesn't run in the simulator). It isn't published to the App Store.

Screenshots: not available yet. I'll add real photos from an actual match once I have them, rather than invent any here.

Stack

Swift, SwiftUI, Speech (SFSpeechRecognizer), AVFoundation, Cloudflare Worker + Azure TTS.
